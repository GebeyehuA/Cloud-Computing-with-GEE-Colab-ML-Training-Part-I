Cloud Computing with Google Earth Engine (GEE), Colab & Machine Learning (Part I)
Course Overview
A comprehensive 3-day intensive training program designed to master cloud-based geospatial analysis, machine learning classification, and environmental monitoring using Google Earth Engine (GEE) and Google Colab. This curriculum bridges fundamental geospatial processing with advanced machine learning workflows using both JavaScript and Python APIs.
Training Schedule & Modules
Day 1: Foundations & Basics
o	Big Geospatial Data & GEE Setup: Introduction to cloud computing for spatial data and account configuration.
o	Earth Engine Basics: Core concepts of the JavaScript API and platform interface.
o	Data Structures & Operations: Managing image collections, filtering, mosaicking, composites, feature collections (CSV, shapefiles), image clipping, and exports.
o	Intermediate Processing: Calculating vegetation indices, cloud masking, image reductions, and generating time series charts.
Day 2: Supervised Classification & Precipitation Analysis
o	Supervised Image Classification: Training data collection, classifier implementation, and accuracy assessment.
o	Advanced Classification: Feature engineering, hyperparameter optimization, and multi-dataset integration (indices, topographic data).
o	Precipitation Time Series: Calculating total rainfall, temporal aggregation, monthly charting, zonal statistics, and trend analysis.
Day 3: Drought Monitoring, Python API & Capstone Project
o	Hydrology & Drought Monitoring: Creating composites, calculating/classifying Vegetation Condition Index (VCI), Temperature Condition Index (TCI), Standardized Precipitation Index (SPI), and annual rainfall averages.
o	GEE Python API & Google Colab: Setting up notebooks, scripts, and executing workflows in a Python environment.
o	Final Guided Project: Land Use/Land Cover (LULC) Mapping and Change Detection using GEE.
