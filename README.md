## 🚀 Course Overview

A comprehensive 3-day intensive training program designed to master cloud-based geospatial analysis, machine learning classification, and environmental monitoring using **Google Earth Engine (GEE)** and **Google Colab**. 

This curriculum bridges fundamental geospatial processing with advanced machine learning workflows, empowering researchers, developers, and GIS professionals to handle petabyte-scale spatial data using both **JavaScript** and **Python APIs**.

---

## 📚 Training Schedule & Modules

### 📅 Day 1: Foundations & Basics
* **Big Geospatial Data & GEE Setup:** Introduction to cloud computing paradigms for spatial data and account configuration.
* **Earth Engine Basics:** Core concepts of the JavaScript API and navigating the platform interface.
* **Data Structures & Operations:** 
  * Managing image collections and filtering
  * Mosaicking and compositing images
  * Handling feature collections (CSV, shapefiles)
  * Image clipping and data exports
* **Intermediate Processing:** Calculating vegetation indices, cloud masking, image reductions, and generating time-series charts.

### 📅 Day 2: Supervised Classification & Precipitation Analysis
* **Supervised Image Classification:** Training data collection, classifier implementation, and rigorous accuracy assessment.
* **Advanced Classification:** Feature engineering, hyperparameter optimization, and multi-dataset integration (incorporating spectral indices and topographic data).
* **Precipitation Time Series:** Calculating total rainfall, temporal aggregation, monthly charting, zonal statistics, and environmental trend analysis.

### 📅 Day 3: Drought Monitoring, Python API & Capstone Project
* **Hydrology & Drought Monitoring:** 
  * Creating composites and assessing droughts
  * Calculating and classifying the **Vegetation Condition Index (VCI)** and **Temperature Condition Index (TCI)**
  * Standardized Precipitation Index (**SPI**) and annual rainfall averages
* **GEE Python API & Google Colab:** Setting up notebooks, managing scripts, and executing scalable workflows in a Python environment.
* **Final Guided Project:** End-to-end Land Use / Land Cover (LULC) Mapping and Change Detection using GEE.

## 🛠️ Prerequisites & Requirements
* A Google account with access to [Google Earth Engine](https://earthengine.signup.info/) enabled.
* A modern web browser.
* Basic familiarity with programming concepts (Python or JavaScript experience is helpful but not strictly required for Day 1).

1. Clone or download this repository.
2. Open the respective Day folders in [Google Colab](https://colab.research.google.com/) or the [Earth Engine Code Editor](https://code.earthengine.google.com/).
3. Follow along with the code snippets and lab exercises provided in each module.
